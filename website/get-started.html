🚀 Five calm steps

Get from zero to a verified PNG.

Install deliberately, inspect your provider, dry-run the plan, then make one explicit request.

⚠️
Before you begin

API calls can be billable. Never put an API key in flags, prompts, files, URLs, or logs. Never auto-retry exit codes 5, 6, or 7.

1. Install

For a tagged release, build from the named source tag:

cargo install --git https://github.com/dmoliveira/codex-image-cli.git \
  --tag v0.1.0 --locked codex-image-cli

Then confirm the binary is available:

codex-image --help

2. Choose a provider

The default is the direct Image API. Put the key in the environment only:

export OPENAI_API_KEY="..."
codex-image doctor --json

Use --provider codex only when you intentionally want the locally authenticated Codex CLI path. A local login does not prove API entitlement.

3. Dry-run first

Create the output directory yourself. It must already exist and contain no symlinked path components.

mkdir -p artifacts/design
codex-image generate \
  --provider api \
  --prompt "A warm editorial fox using a terminal" \
  --output-dir artifacts/design \
  --prefix fox-terminal \
  --n 1 \
  --size 1024x1024 \
  --quality low \
  --dry-run --json

The dry run reads no key, reserves no files, and opens no network connection.

4. Make one request

When the dry-run report looks right, remove only --dry-run:

codex-image generate \
  --provider api \
  --prompt "A warm editorial fox using a terminal" \
  --output-dir artifacts/design \
  --prefix fox-terminal \
  --n 1 --size 1024x1024 --quality low --json

The result is written only after the response decodes and matches the requested image container.

5. Read the report

With --json, stdout contains exactly one JSON document. Start with ok, status, exit_code, outputs, retained_artifacts, and possibly_modified_paths.

💡
Need more control?

Use a versioned --request-file for typed inputs. Keep output naming, overwrite approval, endpoint trust, and insecure-localhost approval as explicit CLI flags.

Safe retry rule

Codes 5, 6, and 7 may follow a POST. Do not submit again automatically. Inspect the report and remote/local state first.

Start small. Validate first. Make one explicit operation.
