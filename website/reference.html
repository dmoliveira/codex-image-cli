Provider capabilities

api

Direct Image API

Default provider. Uses OPENAI_API_KEY. Supports GPT Image 2 parameters, Batch, and manifest Batch runs.

codex

Local Codex CLI

Explicit provider. Uses the authenticated local executable and currently publishes one validated PNG per command.

Endpoint and security rules

  • Keys come only from OPENAI_API_KEY, never CLI flags or files.
  • Redirects and proxies are disabled; credentials never follow a redirect.
  • Loopback HTTP requires --allow-insecure-localhost.
  • Custom HTTPS requires exact repeated --dangerously-allow-api-key-to ORIGIN approval.
  • Output directories must already exist and contain no symlinked components.
